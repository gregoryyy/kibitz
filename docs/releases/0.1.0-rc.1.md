## Deployment and compatibility

- Support remains [local single-user operation](../DEPLOYMENT.md): native Node
  24.22.1 or a maintained patched successor, or the supplied loopback-published
  container. The mock coach is the container default. Hosted accounts and public
  or LAN deployment are outside this candidate's scope.
- This preparation changes package-version metadata and documentation. It adds
  no schema migration. Browser/server export envelopes, private library/usage
  SQLite schema versions, cookie names and storage keys retain the functional
  base's formats. Preserve cookies with their private collection and export data
  before an upgrade; [backup and erasure limits](../DATA.md) still apply.
- Container UID/GID stays `1000:1000`. Earlier packaging compatibility evidence
  reopens a volume with the same current app/schema; it does not test a historical
  schema migration or every operator backup/restore path. Retain the private
  volume and SQLite WAL companions as [documented](../CONTAINER.md).
- Browser-model size/hash pins and filenames remain unchanged by the fixed
  source revisions. Existing checked weights keep their fast path. A new package
  version does not authorize a weight download, Chrome-managed update or provider
  request. The [offline update flow](../OFFLINE.md) waits for old tabs to close.
- Prior native unit/CLI evidence uses macOS/arm64 Node 24.22.1; packaged browser
  evidence uses Linux/amd64 and Chromium. Candidate checks must identify their
  actual platforms. No real-model quality, Firefox/Safari, mobile-hardware or
  alternate-container-architecture certification follows from those tests.
