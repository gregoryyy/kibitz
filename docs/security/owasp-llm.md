## Reproduced limits

At review snapshot `e87364f`, a synthetic Mistral-compatible HTTP 400 through the real OpenAI SDK supplied an error containing its dummy configured credential, without a recognized `sk-`/key prefix. `toGatewayError()` returned `provider_rejected` with that credential in its page-facing message. Only a boolean was printed; no real key, `.env` or external call was used. **Remediated in 11.3.2.1:** public HTTP 400 errors now contain only fixed tool/chat/format/schema/context hints or a generic rejection. Classification reads at most 8192 characters and never returns input substrings. All four adapters and coach/structured/test/embedding routes have real-SDK synthetic tests. Browser regressions use the actual CLI; the credential case is also run against the prior server. Prefix redaction is no longer the boundary for these errors. This does not filter arbitrary model answers, certify a provider, or change existing JSON/SDK retry behavior.

On this source, `checkAnswer()` for the starting board and the false sentence “White has three kings and the queen is immune to capture.” returns zero recognized moves, zero recognized piece claims and `problems: 0`. No provider is involved. The counter measures recognized failures; it is not a correctness score. The UI flags recognized discrepancies and unchecked moves, without proving unrestricted prose true. Do not close 11.3.9 on regex coverage or a benchmark cue score.

A second synthetic probe at the review snapshot used the real OpenAI SDK/adaptor and a loopback HTTP event stream that delivered one text chunk, then stayed open. With `AI_TIMEOUT_MS=100`, `complete()` was still pending after 350 ms; the probe explicitly aborted and closed its resources. **Remediated in 11.3.10.1:** one operation scope now bounds transport/body and SDK iteration/parsing, aborts readers, rejects late results and owns independent counters/signals for concurrent calls. Actual loopback SDK tests cover all four adapters, structured/connection-style requests, embeddings and Ollama metadata; the real gateway connection-test route also propagates disconnects. CLI/browser cases cover private timeout/overflow errors, accounting and German hints. The stalled-body regression is run on prior server `3c0bf82` as well. No external provider or paid service is contacted. [Documented per-call bounds and remaining billing limits](../guide/setup.md#provider-response-bounds) apply; closure does not establish an upstream provider's cancellation behavior.
