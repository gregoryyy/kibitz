Your data

Exports download a JSON file to this device. Deletion is permanent. Close other Kibitz tabs before erasing data so they cannot save old copies again.

This page does not run the game or its autosave. Exports contain saved data; unsaved drafts are not included.

Data in this browser

Games, references, the saved game in progress, preferences, profile, lesson progress, practice schedules and cached coach answers. Browser erasure also removes cached server libraries on this device.

Server records, provider histories, downloaded model files and unrelated website data are handled separately.

This browser's server library

Games and references stored by the optional local server, identified by this browser's private cookie. Browser data is separate. Check the current library before exporting or erasing it.

These controls do not delete conversations retained by an AI provider, other browser profiles, external account libraries or server backups. A server operator must handle those copies separately.

When usage persistence is enabled, the local server keeps daily request, token and cost totals and recent request times under a hashed browser ID. These export and erase controls leave those counters in place; the local operator manages them.
